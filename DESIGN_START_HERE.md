```
TYPOGRAPHY:
Headlines: Manrope (600-800 weight)
Body: Inter (400-600 weight)
Scales: 30px H1, 18px H3, 14px Body, 12px Small

SPACING:
Base: 8px
Sections: 24px (space-y-6)
Fields: 8px (space-y-2)  
Forms: 16px padding (px-4)

COMPONENTS:
Inputs: 44px height, ring-1/ring-2 pattern, blue focus
Buttons: 44px height, gradient primary, scale(1.02) hover
Cards: 12px radius, white background, subtle shadow
Navigation: Sticky header, fixed bottom bar (mobile)

RESPONSIVE:
Mobile: Single column, 16px padding
Tablet (md): 2-column grid
Desktop (lg): 8-col content + 4-col sidebar
```
