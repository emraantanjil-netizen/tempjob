## 🚀 3-Step Deployment

1. **GitHub**
   - Initialize git
   - Push code to main branch

2. **Vercel**
   - Import from GitHub
   - Add environment variables
   - Click Deploy

3. **Go Live**
   - Site at `your-project.vercel.app`
   - HTTPS automatic
   - Global CDN active

# 1. Node version: node --version (should be 18+)
