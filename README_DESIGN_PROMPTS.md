## 📋 Quick Reference

### Design System Specs (From UI_DESIGN_PROMPT.md)
```
Colors:
  Primary: #2563EB (Blue)
  Success: #10B981 (Green)
  Accent: #F59E0B (Amber)
  Text: #1F2937 (Dark Gray)
  BG: #F3F4F6 (Light Gray)

Typography:
  Heading: 24px, weight 700
  Subheading: 18px, weight 600
  Body: 14px, weight 400
  Caption: 12px, weight 400

Components:
  Button: 48px height, 12px radius
  Card: 12px radius, 16px padding
  Input: 44px height, 12px radius
  Grid: 8px base unit
```

### The 7 Screens (From UI_DESIGN_PROMPT.md)
1. **Login** - Email/password form + Google OAuth
2. **Register** - Multi-step form (name, email, password, phone, role)
3. **Job List** - Scrollable job cards with filters
4. **Job Detail** - Full job information + sticky Apply button
5. **Post Job** - 3-step form for employers to create jobs
6. **My Applications** - Tabbed view of application status
7. **Profile** - User info, settings, verification status
