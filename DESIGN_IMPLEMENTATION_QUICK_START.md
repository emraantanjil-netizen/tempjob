## ❓ FAQs & Common Issues

### Q: The designs use absolute positioning, how do I convert to responsive CSS?

**A**: Use this pattern:
```html
<!-- From (absolute): -->
<div style="position: absolute; left: 0; top: 0; width: 375px;">

<!-- To (responsive): -->
<div class="w-full max-w-md mx-auto flex flex-col">
```

### Q: Which color should I use for the secondary green?

**A**: Use `#006A4E` (the actual design value). Update your design tokens if needed.

### Q: How do I handle form validation?

**A**: See IMPLEMENTATION_GUIDE_BY_SCREEN.md → Form Group Component section for error state patterns.

### Q: What's the responsive breakpoint strategy?

**A**: Mobile-first (375px default), then consider 768px (tablets) and 1024px (desktop) based on backend support.

### Q: Can I modify the component styling?

**A**: Yes! Use the specs as guidelines. Stay true to:
- Color values
- Font sizes and weights
- Spacing (8px base unit)
- Border radius patterns
- Shadow depth

### Q: How should I structure the project?

**A**: Suggested structure:
```
project/
├── src/
│   ├── components/      # UI components
│   ├── screens/         # Full page screens
│   ├── styles/          # Tailwind config
│   ├── utils/           # Helpers, API calls
│   └── index.html
├── tailwind.config.js
├── package.json
└── README.md
```
